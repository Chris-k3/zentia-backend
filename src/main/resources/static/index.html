🔐 Arquitectura de Autenticación (Frontend React ↔ Backend Render ↔ BD Supabase)

Importante: No se usa Supabase Auth en el frontend. Supabase funciona únicamente como la base de datos PostgreSQL conectada al backend de Spring Boot en Render. Toda la sesión se maneja con el JWT propio de Zentia que devuelve el backend. 

[1] Usuario hace clic en "Continuar con Google" en React (@react-oauth/google)
        │
        ▼
[2] Google devuelve credencial OAuth (idToken / datos de perfil) al Frontend
        │
        ▼
[3] Frontend hace POST https://zentia-backend-5l77.onrender.com/api/v1/auth/google
    (Puede enviar { googleId, email, name, pictureUrl, idToken } o solo { idToken })
        │
        ▼
[4] Backend en Render busca/crea el usuario en Supabase (tabla "users")
    y firma un Token JWT propio de Zentia (válido por 24h)
        │
        ▼
[5] Backend responde: { token, userId, email, name, onboardingCompleted, newUser }
        │
        ├──► Si onboardingCompleted === false:
        │      Frontend redirige a pantalla de Onboarding (/onboarding)
        │      y envía POST /api/v1/users/onboarding con Authorization: Bearer <token>
        │
        └──► Si onboardingCompleted === true:
               Frontend redirige al Dashboard (/dashboard) y consulta:
               • GET /api/v1/users/financial-profile
               • GET /api/v1/transactions/dashboard?startDate=...&endDate=...
✅ 1. Lo que necesitas TÚ (Backend en Render + Supabase + Google Cloud)
A. Variables de Entorno en Render: 
SPRING_DATASOURCE_URL=jdbc:postgresql://aws-0-<REGION>.pooler.supabase.com:6543/postgres?ssl=true&sslfactory=org.postgresql.ssl.NonValidatingFactory&prepareThreshold=0
SPRING_DATASOURCE_USERNAME=postgres.<PROJECT_REF>
SPRING_DATASOURCE_PASSWORD=<TU_PASSWORD_DE_SUPABASE>
PORT=8080
JWT_SECRET=<CLAVE_SECRETA_LARGA_PARA_FIRMAR_JWT>
⚠️ Nota: En el pooler de Supabase puerto 6543, asegúrate de incluir &prepareThreshold=0 al final del URL para evitar errores de prepared statements en Hibernate.
B. Google Cloud Console (Orígenes autorizados de JavaScript): En tu cliente OAuth 2.0 (Aplicación web), agrega todos los orígenes desde donde el navegador abrirá el botón de Google: 
https://zentia-backend-5l77.onrender.com
http://localhost:5173
http://localhost:3000
Y cuando despliegues el frontend (Vercel/Netlify), agrega también esa URL. Comparte únicamente el Client ID con tu compañero (nunca el Client Secret).
C. Categorías iniciales en Supabase: Asegúrate de tener registros en la tabla categories en Supabase para que el frontend pueda listarlos y enviar priorityCategoryId en el Onboarding.

3. Ejemplo Completo de Login con Google + Redirección a Onboarding en React

              
El backend soporta recibir tanto el idToken directo de <GoogleLogin /> como el objeto completo con googleId, email, name, pictureUrl.

            

            
          

          
import { GoogleLogin } from '@react-oauth/google';
import { zentiaApi } from '../api/zentiaClient';

export function LoginButton({ onLoginSuccess }: { onLoginSuccess: (onboardingCompleted: boolean) => void }) {
  return (
    <GoogleLogin
      onSuccess={async (credentialResponse) => {
        if (!credentialResponse.credential) return;

        // El backend de Zentia decodifica automáticamente el idToken de Google
        // (o también puedes enviar googleId, email, name, pictureUrl explícitamente)
        const authData = await zentiaApi.loginWithGoogle({
          idToken: credentialResponse.credential,
          googleId: '',
          email: '',
          name: '',
        });

        // 1. Guardar el JWT propio de Zentia para futuras peticiones protegidas
        localStorage.setItem('zentia_token', authData.token);

        // 2. Redirigir según si ya completó el cuestionario de Onboarding
        onLoginSuccess(authData.onboardingCompleted);
      }}
      onError={() => {
        console.error('Error al iniciar sesión con Google');
      }}
    />
  );
}

export type TransactionType = 'INGRESO' | 'GASTO';

export interface GoogleAuthRequestDTO {
  googleId: string;
  email: string;
  name: string;
  pictureUrl?: string;
  idToken: string;
}

export interface AuthResponseDTO {
  token: string;
  userId: number;
  email: string;
  name: string;
  onboardingCompleted: boolean;
  newUser: boolean; // Serializado por Jackson desde isNewUser()
}

export interface UserResponseDTO {
  id: number;
  name: string;
  email: string;
  pictureUrl: string | null;
  onboardingCompleted: boolean;
  phoneNumber: string | null;
}

export interface FinancialProfileRequestDTO {
  monthlyIncome: number;
  monthlySavingsGoal: number;
  estimatedMonthlyExpense?: number | null;
  priorityCategoryId?: number | null;
}

export interface FinancialProfileResponseDTO {
  userId: number;
  monthlyIncome: number;
  monthlySavingsGoal: number;
  estimatedMonthlyExpense: number | null;
  priorityCategoryId: number | null;
  priorityCategoryName: string | null;
  onboardingCompleted: boolean;
}

export interface Category {
  id: number;
  name: string;
  type: TransactionType;
  icon: string | null;
}

export interface TransactionRequestDTO {
  categoryId: number;
  amount: number;
  type?: TransactionType; // Requerido al crear (POST), ignorado al actualizar (PUT)

}

export interface TransactionResponseDTO {
  id: number;
  description: string;
  amount: number;
  date: string; // "YYYY-MM-DD"
  type: TransactionType;
  categoryName: string;
}

export interface DashboardSummaryDTO {
  totalIngresos: number;
  totalGastos: number;
  balanceActual: number;
}

        


        

          

            

              
2. Cliente HTTP con Axios + Interceptor JWT (src/api/zentiaClient.ts)

              
Funciones listas para importar en tus componentes o hooks de React.

            

            
          

          
import axios from 'axios';
import type {
  GoogleAuthRequestDTO,
  AuthResponseDTO,
  UserResponseDTO,
  FinancialProfileRequestDTO,
  FinancialProfileResponseDTO,
  Category,
  TransactionRequestDTO,
  TransactionResponseDTO,
  DashboardSummaryDTO,
} from '../types/zentia';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'https://zentia-backend-5l77.onrender.com/api/v1',
  headers: {
    'Content-Type': 'application/json',
  },
});

// Inyecta automáticamente el token JWT en cada petición protegida
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('zentia_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export const zentiaApi = {
  // 1. Auth con Google (POST /api/v1/auth/google)
  loginWithGoogle: (data: GoogleAuthRequestDTO) =>
    api.post<AuthResponseDTO>('/auth/google', data).then((r) => r.data),

  // 2. Solicitar OTP (POST /api/v1/auth/otp/solicitar?phoneNumber=...)
  requestOtp: (phoneNumber: string) =>
    api.post<{ message: string }>('/auth/otp/solicitar', null, { params: { phoneNumber } }).then((r) => r.data),

  // 3. Verificar OTP (POST /api/v1/auth/otp/verificar?phoneNumber=...&codigo=...)
  verifyOtp: (phoneNumber: string, codigo: string) =>
    api.post<{ message: string; token: string }>('/auth/otp/verificar', null, {
      params: { phoneNumber, codigo },
    }).then((r) => r.data),

  // 4. Vincular teléfono (PUT /api/v1/users/profile/phone?userId=...&phoneNumber=...)
  linkPhone: (userId: number, phoneNumber: string) =>
    api.put<UserResponseDTO>('/users/profile/phone', null, {
      params: { userId, phoneNumber },
    }).then((r) => r.data),

  // 5. Completar Onboarding / Guardar perfil financiero (POST /api/v1/users/onboarding) - Requiere JWT
  completeOnboarding: (data: FinancialProfileRequestDTO) =>
    api.post<FinancialProfileResponseDTO>('/users/onboarding', data).then((r) => r.data),

  // 6. Consultar perfil financiero (GET /api/v1/users/financial-profile) - Requiere JWT
  getFinancialProfile: () =>
    api.get<FinancialProfileResponseDTO>('/users/financial-profile').then((r) => r.data),

  // 7. Listar categorías (GET /api/v1/categories)
  getCategories: () =>
    api.get<Category[]>('/categories').then((r) => r.data),

  // 6. Registrar transacción (POST /api/v1/transactions) - Requiere JWT
  createTransaction: (data: TransactionRequestDTO) =>
    api.post<TransactionResponseDTO>('/transactions', data).then((r) => r.data),

  // 7. Consultar historial por rango (GET /api/v1/transactions/historial) - Requiere JWT
  getHistory: (startDate: string, endDate: string) =>
    api.get<TransactionResponseDTO[]>('/transactions/historial', {
      params: { startDate, endDate },
    }).then((r) => r.data),

  // 8. Resumen Dashboard (GET /api/v1/transactions/dashboard) - Requiere JWT
  getDashboardSummary: (startDate: string, endDate: string) =>
    api.get<DashboardSummaryDTO>('/transactions/dashboard', {
      params: { startDate, endDate },
    }).then((r) => r.data),

  // 9. Actualizar transacción (PUT /api/v1/transactions/{transactionId}) - Requiere JWT
  updateTransaction: (transactionId: number, data: Pick<TransactionRequestDTO, 'categoryId' | 'amount' | 'description'>) =>
    api.put<TransactionResponseDTO>(`/transactions/${transactionId}`, data).then((r) => r.data),

  // 10. Eliminar transacción (DELETE /api/v1/transactions/{transactionId}) - Requiere JWT
  deleteTransaction: (transactionId: number) =>
    api.delete(`/transactions/${transactionId}`),
};
